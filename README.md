# mli746.github.io

Personal website of Miao Li, served by GitHub Pages at https://mli746.github.io/.

It is a single static page with no build step:

- `index.html`: all content (bio, news, publications, research, experience)
- `css/style.css`, `js/main.js`: styling, dark mode, and the hero animation
- `files/cv.pdf`: the CV linked from the site
- `images/`: photo and favicon

To update, edit `index.html` and push to `main`. `.nojekyll` tells GitHub Pages to serve the files as-is.
